# Ayesha Web Studio — Website

A responsive, animated static website using the supplied Ayesha Web Studio logo.

## Files
- `index.html` — main website
- `styles.css` — design, responsive layout, colors and animations
- `script.js` — mobile menu, scroll reveal and WhatsApp enquiry form
- `privacy.html` — privacy policy starter page
- `terms.html` — terms of use starter page
- `assets/ayesha-web-studio-logo.jpeg` — your supplied logo

## Edit it easily
You can edit the HTML/CSS/JS directly in GitHub:
1. Open a file in your repository.
2. Click the pencil icon.
3. Make changes and commit them.

To change the colors, edit the CSS variables at the top of `styles.css` (`--teal`, `--gold`, `--cream`, etc.).
To change the WhatsApp contact, search for `923243424462` in `index.html` and `script.js` and replace it with your number in international format without `+`, spaces or dashes.
Social profile URLs are in the contact section of `index.html`.
To add real portfolio work, edit the cards inside `#work`. The current previews are explicitly illustrative concepts, not claimed client projects.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of this ZIP (upload the files and `assets` folder, not the ZIP itself).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish your site.

You can also import the repository into Vercel and deploy it as a static site. No build command or framework is required.

## Contact form
The contact form opens WhatsApp with the details pre-filled. The visitor must press Send in WhatsApp. The site does not save form submissions to a database.

## Before launch
- Check every social link and contact detail.
- Review the privacy policy and terms for your actual business practices.
- If you add analytics, advertising, payments or a server-based form, update the privacy policy.
- Replace concept previews with real work when available.
